# 云朵助手 · CHAJ

给 SillyTavern 1.19.0 的界面扩展。点悬浮球打开「潮汐镜」，左右拖动转盘切换功能，点转盘打开当前功能。功能目录已有「历史楼层」和「开场白工作台」，其余位置预留。右上角可切换日间、夜间和界面语言。

## 安装

在酒馆点「扩展 → 安装扩展」，粘贴 `https://github.com/wq70/CHAJ.git`。安装发生在运行酒馆的设备上，手机访问同一个酒馆时会看到云朵。

手动安装时，把整个 `CHAJ` 文件夹复制到酒馆的 `data/<用户名>/extensions/`。安装后的路径应为 `data/<用户名>/extensions/CHAJ/manifest.json`。重新打开酒馆页面加载扩展。此扩展使用酒馆自带的接口，界面资源随扩展一起安装。

## 开场白工作台

打开单人角色聊天，在潮汐镜中进入「开场白工作台」。可一次添加 1 条或 2 条真正为空的备选开场白，也可以编辑、用分组筛选、复制分支、删除。分组与开场白一同保存到角色卡。本次打开酒馆期间可逐步撤销最近 12 次操作。

如果聊天里只有角色的首条消息，面板会同步角色卡中缺失的切换项。卡里已经保存的空白开场白也会补进来。点击「切换到此开场」可直接选中。已开始对话的会话可以点「用此开场新建聊天」，在另一条聊天中使用选中的开场白。

## 历史楼层

在潮汐镜中进入「历史楼层」。面板显示当前会话的可查楼层范围和分页列表，支持搜关键词、说话者或 `#120` 这样的楼层号。编号和酒馆一致，从 `#0` 开始。

点结果阅读该楼的原始文本，可以在预览里查看上一楼或下一楼。已经加载到聊天页的楼层支持「跳到聊天」。尚未显示的楼层直接在面板预览，因此查旧消息时可以继续使用酒馆的「加载消息数」设置。可搜索范围为酒馆当前已读入会话的消息，包含未绘制到聊天页的旧楼层。

## 插件设置

- **外观**可选择潮汐或纯白／纯黑配色，两套都支持日间和夜间。
- **悬浮球**可以拖动，位置会保存在当前浏览器。隐藏后，在屏幕右边缘的中段用双击、三连击或向左划唤醒，也可以从酒馆的「扩展 → 云朵助手设置」取消隐藏。
- **更新提醒**默认开启。通过 Git 链接安装后，扩展最多每六小时检查一次，发现更新时可以选择更新并刷新或稍后提醒。关闭后停止自动检查和提醒。
- **功能配置**可调整历史楼层的默认排序和开场白列表的分组标签。
