# 云朵助手 · CHAJ

给 SillyTavern 1.19.0 的中文界面扩展。手机和电脑打开酒馆后，点右下角的云朵打开面板。

## 安装

在酒馆点「扩展 → 安装扩展」，粘贴 `https://github.com/wq70/CHAJ.git`。安装发生在运行酒馆的设备上，手机访问同一个酒馆时会看到云朵。

手动安装时，把整个 `CHAJ` 文件夹复制到酒馆的 `data/<用户名>/extensions/`。安装后的路径应为 `data/<用户名>/extensions/CHAJ/manifest.json`。重新打开酒馆页面加载扩展。此扩展使用酒馆自带的接口，界面资源随扩展一起安装。

## 空白开场白

打开单人角色聊天，点云朵 →「空白开场白」，可一次添加 1 条或 2 条真正为空的备选开场白。保存后，面板马上显示空白条数和新增位置。尚未开始对话的当前聊天也会立即更新首条消息的切换项。已有对话的会话保留原来的开场白。新增开场白也可以在角色卡的备选开场白编辑器里填写。

## 历史楼层

点云朵 →「历史楼层」。面板显示当前会话的可查楼层范围和分页列表，支持搜关键词、说话者或 `#120` 这样的楼层号。编号和酒馆一致，从 `#0` 开始。

点结果阅读该楼的原始文本，可以在预览里查看上一楼或下一楼。已经加载到聊天页的楼层支持「跳到聊天」。尚未显示的楼层直接在面板预览，因此查旧消息时可以继续使用酒馆的「加载消息数」设置。可搜索范围为酒馆当前已读入会话的消息，包含未绘制到聊天页的旧楼层。
